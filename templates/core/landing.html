How it works

Submit

Users declare phones, laptops, batteries, chargers, cables and monitors for recycling.

2

Doorstep pickups move Pending → Assigned → In Transit → Collected → Processing → Recycled.

3

4

Recycle

Facilities log recyclable, reusable, hazardous and residual fractions with completion dates.

Why e-waste management matters

E-waste is the fastest-growing waste stream in the world. A single phone battery can contaminate soil and water for decades — but the same devices contain copper, gold, aluminium and rare plastics that can be recovered.

  • Hazardous materials (lead, mercury, lithium) need safe handling
  • Doorstep pickup removes friction for citizens
  • Smart bins prevent overflowing collection points
  • Recycling records prove material actually gets recovered

System architecture

ESP32 → REST API → Django → DB → Dashboard
Users → Website → Django API → DB
Admin → Dashboard → Django API → DB

Simple polling first; WebSockets only if the core is stable.

Smart bins

Each bin has a unique ID (e.g. ECO-BIN-001), location, fill %, weight, temperature, online status and last-seen timestamp.

POST /api/telemetry/  →  {"device_id": "ECO-BIN-001", "fill_level": 82, "weight": 18.4, "temperature": 29.5}

Telemetry API + live bin dashboard arrive on Day 4. Simulation mode (POST /api/telemetry/simulate/) arrives Day 5 and is always labelled SIMULATED.
